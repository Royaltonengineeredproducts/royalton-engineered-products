# Royalton Engineered Products Website

Static website prepared for GitHub Pages.

## Upload to GitHub
1. Open the `royalton-engineered-products` repository.
2. Click **Add file → Upload files**.
3. Upload **the contents of this folder** (index.html, styles.css, script.js, and the assets folder), not the outer folder itself.
4. Commit the files to the `main` branch.
5. GitHub Pages will rebuild automatically.

## Before final launch
- Connect the Request a Quote form to the business email/form service you want to use.
- Add the final business phone/email/address if desired.
- Connect the custom domain after the GitHub Pages version is approved.

The current quote form creates a formatted quote request and copies it to the visitor's clipboard; it does not send email yet.
